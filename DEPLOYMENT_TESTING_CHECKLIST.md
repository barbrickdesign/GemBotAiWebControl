## 🔧 TROUBLESHOOTING QUICK REFERENCE

**If server won't start:**
1. Check if port 8000 is in use: `netstat -ano | findstr :8000`
2. Kill existing process: `Get-Process node | Stop-Process -Force`
3. Restart server: `node simple-server.js`

**If HTML won't load:**
1. Check file exists: `Test-Path GemBot_Control_AI.html`
2. Check file size: `(Get-Item GemBot_Control_AI.html).Length`
3. Check server logs in browser console (F12)

**If Arduino won't connect:**
1. Check Arduino is plugged in
2. Check port detection: Click "SCAN" button
3. Check baud rate is 9600
4. Check COM port in Device Manager

**If camera won't work:**
1. Check camera is plugged in
2. Grant permission if prompted
3. Check browser hasn't been denied access
4. Try different browser

**If Merlin won't speak:**
1. Check volume is not muted
2. Check speaker is connected
3. Check browser has audio permission
4. Reload page (F5)
