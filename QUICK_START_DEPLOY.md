## ⚡ 5-MINUTE DEPLOYMENT

### Step 1: Open the File (30 seconds)
1. Go to: `domain-configs/the-autobots_com_INJECT.html`
2. Open in any text editor
3. Press **Ctrl+A** (Select All)
4. Press **Ctrl+C** (Copy)

### Step 2: Squarespace Setup (2 minutes)
1. Log into **Squarespace**
2. Select **the-autobots.com** site
3. Click **Settings** (gear icon)
4. Click **Advanced**
5. Click **Code Injection**
6. Find the **HEADER** section
7. Click inside the header box
8. Press **Ctrl+V** (Paste)
9. Click **Save** (top right)

### Step 3: Verify It Works (2.5 minutes)
1. Open new tab: **https://the-autobots.com**
2. You should see:
   - ⚡ Loading indicator with "Loading GemBot: the-autobots.com"
   - 🤖 Domain badge (top-left): "🤖 the-autobots.com Agent Hub"
   - 🧙 Merlin card appears (bottom-right) in red/blue colors
   - 📊 Activity feed (bottom-right)
   - Console message: "GEMBOT AGENT HUB: the-autobots.com"

### Step 4: Test Features (1 minute)
1. **Click Merlin card** → Type "hello" → Send
2. **Watch activity feed** → Should see your message
3. **Wait 30-60 seconds** → Agent actions appear
4. **Open console (F12)** → Check for errors (should be none)

### ✅ SUCCESS!
If you see Merlin, the activity feed, and no errors → **YOU DID IT!** 🎉

## 🔧 Troubleshooting

### "Nothing appears after pasting code"
**Fix:** Wait 2-3 minutes, then hard refresh (Ctrl+F5)

### "Scripts fail to load"
**Fix:** Verify GitHub Pages enabled:
```
https://github.com/barbrickdesign/GemBotAiWebControl
Settings → Pages → Source: main → /root → Save
```

### "Merlin not visible"
**Fix:** Check console (F12) for errors. Look for red text.

### "Wrong colors showing"
**Fix:** Make sure you copied the RIGHT file for the domain!
- the-autobots.com → `the-autobots_com_INJECT.html`
- realhogwarts.com → `realhogwarts_com_INJECT.html`
- etc.
