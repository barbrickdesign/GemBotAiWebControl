## 🎮 Game Concept

**GemBot Machine Farm** is an idle tycoon game where players build and manage a **farm of automated gemstone cutting machines**. Not a traditional farming game with planting crops—this is about deploying industrial CNC gemstone faceting robots that work 24/7 cutting real gemstone designs!

### Core Loop
```
Deploy Machines → Cut Gems Automatically → Collect Finished Stones → 
Trade in Marketplace → Earn $GBUV Tokens → Upgrade Machines → Repeat
```

## 🏭 What is a "Machine Farm"?

A **Machine Farm** is a collection of **automated GemBot gemstone cutting machines**:

- **Not agriculture**: We don't "plant" or "harvest" gems
- **Industrial automation**: Deploy CNC machines that cut gems continuously
- **Idle mechanics**: Machines work even when you're offline
- **Real-world inspired**: Based on actual GemBot Mini faceting machines

## 💎 Gameplay Mechanics

### 1. Deploy Machines
- **Click "Deploy Machine"** to add a new automated cutter to your farm
- Machines are placed in 3D rooms (home desk, workshop, factory)
- Each machine cuts gems based on its speed and quality rating
- Machines work **24/7 automatically** (idle mechanics)

### 2. Collect Gems
- **Click "Collect Gems"** to gather finished gemstones
- Machines produce different gem types based on rough material loaded
- Quality varies: Fair → Good → Excellent → Exceptional
- Carat weight affects value (larger = more valuable)

### 3. Upgrade Machines
- **Click "Upgrade Machine"** to improve:
  - **Cutting Speed**: Finish stones faster
  - **Quality Rate**: Higher chance of excellent cuts
  - **Efficiency**: Less waste, better yield
  - **Automation**: Longer offline production

### 4. Trade in Marketplace
- Sell finished gems for **$GBUV tokens**
- Buy rough gemstones to keep machines running
- Trade precious metals (gold, silver, platinum)
- **Forge jewelry**: Combine gems + metals = rings/necklaces

## 📊 Economy Overview

### Resource Types

1. **Gems (In-Game Currency)**
   - Earned by collecting finished stones
   - Used to deploy/upgrade machines
   - Can be converted to $GBUV

2. **$GBUV Tokens (Crypto)**
   - Earned through gameplay
   - Used for premium features
   - Tradeable on exchanges

3. **Rough Gemstones (Materials)**
   - Raw materials for cutting
   - Buy from shop or find in-game
   - Different types: Amethyst, Ruby, Diamond, etc.

4. **Precious Metals (Materials)**
   - Gold, Silver, Platinum, Rose Gold
   - Used for jewelry forging
   - Purchased with $GBUV

5. **Finished Gems (Products)**
   - Cut and polished gemstones
   - Varying quality and carats
   - Sold for profit or used in forging

### Value Chain
```
Rough Stone ($2-$2000/carat) 
    → Machine Cuts It (time + skill)
    → Finished Gem (2x-10x value)
    → Trade/Forge (earn $GBUV)
    → Buy More Machines
    → Scale Up Farm
```
