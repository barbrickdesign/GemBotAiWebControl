## 📞 WHEN YOU NEED HELP

### For Server Issues
1. Check: Is simple-server.js running?
2. Verify: `Get-Process node`
3. Restart: Kill process and run `node simple-server.js`
4. Check: Can you access http://localhost:8000/?

### For Hardware Issues
1. Check: Is Arduino plugged in?
2. Verify: Click "SCAN" button
3. Select: Correct port from dropdown
4. Test: Try "CONNECT" button
5. Debug: Check browser console (F12)

### For Vision Issues
1. Check: Is camera plugged in?
2. Grant: Camera permission when prompted
3. Wait: TensorFlow model loading (10-30 sec)
4. Test: Point camera at objects
5. Adjust: Brightness/Contrast sliders

### For AI Issues
1. Check: Volume not muted
2. Grant: Microphone permission
3. Test: Type a message first
4. Try: Reload page (F5)
5. Check: Browser console for errors

### For General Issues
1. Open browser console (F12)
2. Look for red error messages
3. Take screenshot of error
4. Note what you were doing
5. Check console logs for clues
6. Read relevant documentation file
