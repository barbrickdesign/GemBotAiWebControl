## What You'll Learn (In Order)

### 🧭 Lesson 1: Touch Screen Menu Structure
**Understand the Nextion menu hierarchy**
- Main Menu (5 options)
- Design Menu (8 cutting phases)
- Manual Control
- Settings
- Switch Test

**Learn**: How the touch screen is organized and what each section does

---

### 🎯 Lesson 2: Web Menu Control
**Use the web buttons to navigate touch screen menus**
- **◀ LEFT button** (Command 1) - Go back/up
- **✓ ENTER button** (Command 0) - Select/confirm
- **▶ RIGHT button** (Command 3) - Go forward/down
- **SYNC button** - Update from touch screen

**Learn**: How to navigate the touch screen from your web browser

---

### 🎮 Lesson 3: Motion Control (D-PAD)
**Move the machine using directional buttons**
- **⬆ UP** - Move toward the lap
- **⬇ DOWN** - Move away from lap
- **◀ LEFT** - Rotate counter-clockwise
- **▶ RIGHT** - Rotate clockwise
- **STEP vs CONTINUOUS** mode difference

**Learn**: How to position the stone using the web interface

---

### ⚙️ Lesson 4: Mode & Speed Control
**Control how fast and precise the machine moves**
- **STEP MODE**: Click once = move once (precision)
- **CONTINUOUS MODE**: Hold = smooth motion (flow)
- **Speed 1-2**: Polishing (slow & precise)
- **Speed 3**: Balanced work
- **Speed 4-5**: Roughing (fast & aggressive)

**Learn**: When to use each speed and mode for different tasks

---

### 📚 After Mastering Fundamentals
You'll be ready for:
- Cutting phase techniques
- Stone-specific properties
- Advanced positioning strategies
- Emergency procedures
