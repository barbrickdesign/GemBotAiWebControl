Key Safety Features

P-axis Safety Gate (Lines ~1000, ~1010):

case 'q':  // P CCW

case 'e':  // P CW


  if (digitalRead(LimitY) == HIGH) {  // Only execute if Y limit NOT pressed


    // Execute P motor step


  }

Why: Prevents P-axis collision when Y is already at the wheel (Y limit pressed).
