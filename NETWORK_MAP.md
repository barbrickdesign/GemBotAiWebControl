## 🔗 Network Communication Flow

```
User Visits Domain → Loads GemBot → Connects to Central Hub
         ↓
    Initializes Wallet → Connects to Solana Blockchain
         ↓
    Spawns 4 Agents → Begin Activity Logging
         ↓
    Enables Cross-Domain Features:
    • Trade with other domains
    • View global leaderboard
    • Transfer items
    • Unlock network achievements
    • Communicate with agents on other domains
```
