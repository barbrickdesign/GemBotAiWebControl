## 🚀 Deployment Instructions

### For Each Domain:

1. **Open DOMAIN_TEMPLATE.html** in this repository
2. **Replace all {{PLACEHOLDERS}}** with values from above
3. **Copy the completed code**
4. **Go to Squarespace:** Settings → Advanced → Code Injection
5. **Paste in HEADER section**
6. **Save and visit your site**

### Bulk Deployment (Recommended):

Use the provided Python script to generate all 15 customized files automatically:

```python
# Run: python generate_domain_configs.py
```

This will create 15 ready-to-paste files in `/domain-configs/` folder.
