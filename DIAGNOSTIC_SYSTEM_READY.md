## How to Use

### For End Users
1. Click **🔧 DIAGNOSTIC** in the top toolbar
2. Tell Merlin your name (once)
3. Answer 7 questions about your machine
4. Review results
5. Follow repair steps if needed

### For Developers
```javascript
// Start diagnostic programmatically
merlin.startDiagnostic();

// Or click the button in the UI
```
