- Welcome bonuses (100 GBUV to new users)

## 🔐 **Security Model:**

### Core Wallet (Hot Wallet):
- Auto-generated by system
- Private key stored in localStorage (encrypted in production)
- Only handles operational amounts (100K GBUV max)
- Daily transaction limits
- Fraud detection enabled

### User Wallets (Custodial):
- System manages all user wallets
- Users can export keys if they want
- Backup system (coming soon)
- Insurance fund for protection

### Your Admin Wallet (Cold Storage):
- YOU control this
- Holds majority of GBUV
- Only used for refilling core wallet
- Hardware wallet recommended

## 🎮 **Integration Examples:**

### Example 1: Reward User for Level Up
```javascript
// In your game code:
function onLevelUp(userId, newLevel) {
    // Automatically distributes: newLevel × 50 GBUV
    await window.gemBotWalletSystem.rewardLevelUp(userId, newLevel);
    
    // User sees: "🎉 Level 5! You earned 250 GBUV!"
    // No wallet interaction needed!
}
```

### Example 2: Pay Agent Salary
```javascript
// In agent system:
setInterval(async () => {
    for (let agent of agents) {
        // Automatically pays 10 GBUV to each agent
        await window.gemBotWalletSystem.payAgentSalary(agent.id);
    }
}, 24 * 60 * 60 * 1000); // Every 24 hours
```

### Example 3: Create New User
```javascript
// When user signs up:
async function onUserSignup(userId, username) {
    // System automatically:
    // 1. Creates Solana wallet
    // 2. Sends 100 GBUV welcome bonus
    // 3. Logs to activity feed
    const wallet = await window.gemBotWalletSystem.createUserWallet(
        userId, 
        username
    );
    
    console.log(`User ${username} wallet: ${wallet.publicKey}`);
}
```
