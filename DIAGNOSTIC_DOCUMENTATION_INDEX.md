## 🚀 How to Deploy

### For End Users
1. Click the **🔧 DIAGNOSTIC** button
2. Enter your name when prompted
3. Answer 7 simple questions
4. Review the results
5. Follow repair steps if needed

### For Developers
```javascript
// In browser console
merlin.startDiagnostic();

// Or use the UI button
// Click: 🔧 DIAGNOSTIC
```

### For System Admins
1. Backup existing files
2. Deploy GemBot_Control_AI.html
3. Clear browser cache
4. Verify button appears in toolbar
5. Test with a sample user
6. Monitor console logs
