## 📞 **Troubleshooting Testing Issues**

### If Merlin doesn't appear:
1. Reload page completely (Ctrl+Shift+R)
2. Check browser console for errors (F12)
3. Verify file was saved correctly
4. Check file line count is ~3,350+

### If responses are generic:
1. Verify new GemBotAI methods exist
2. Check that `getAboutMerlin()` exists
3. Verify `handleStoneQuestion()` is called
4. Check knowledge base has 6 categories

### If stone detection fails:
1. Try exact stone names: "diamond", "ruby", etc.
2. Check `detectStoneType()` method exists
3. Verify `currentStone` property updates
4. Try phrase like "I'm cutting a diamond"

### If voice doesn't work:
1. Check microphone/speaker enabled
2. Try different browser
3. Verify voice settings in localStorage
4. Test manual voice in browser settings
