## How to Use It

### Step 1: Access the System
```
Browser: http://127.0.0.1:8000/GemBot_Control_AI.html
(Server already running)
```

### Step 2: Start Using
```
1. Click START CAMERA
2. Wait 3-5 seconds for TensorFlow.js to load
3. See "✅ ML model loaded successfully!" in chat
4. Point camera at objects
5. See green bounding boxes
6. Read AI suggestions
```

### Step 3: Record a Session (Optional)
```
1. With camera running, click RECORD
2. Operate GemBot normally
3. Click RECORD again to stop
4. Message: "✅ Session saved (ID: ...)"
5. Check IndexedDB in DevTools
```

### Step 4: Connect Arduino (Optional)
```
1. Click SCAN
2. Select your USB device
3. Click CONNECT
4. Status → CONNECTED (green)
5. Click motor buttons to control
```
