## 🔄 Data Flow (How It Works)

```
Every Frame (60fps):
└─ Camera captures video

Every 30 Frames (~500ms):
├─ ML detects objects
├─ Features extracted (brightness, focus)
└─ [NEW] updateAIVisionContext() called
    └─ aiVisionContext updated with detection data

User Sends Message:
├─ getConversationalResponse(query) called
├─ Gets: visionData = this.getVisionData()
├─ Passes: visionData to getSmartContextResponse()
└─ Vision-aware patterns match
    └─ AI response includes "what it sees"
```
